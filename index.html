Проекты

01 · обработка данных

Поиск водителей-нарушителей скорости

Подрядчики возили грузы на самосвалах. GPS фиксировал превышения скорости, но знал только машину, а не водителя. Я сделал сервис, который сводит телеметрию с журналами весовых и находит, кто был за рулём. Результат идёт юристам для претензий.

2 млнстрок телеметрии: координаты и скорость каждые несколько секунд
200 тыс.строк регистраций водителей в двух таблицах
→ 600превышений скорости с найденным водителем: готовая таблица для претензий
  • Нормализация номеров: латиница → кириллица, срезание «КАМАЗ», «ШАХМАН», «JAC» и мусорных символов
  • Приведение времени из разных форматов и часовых поясов к UTC
  • Сопоставление по госномеру и 30-минутному окну времени на Polars
  • Запись в PostgreSQL пачками по 1000 строк в одной транзакции
  • REST API, админ-панель и выгрузка результата в CSV и Excel
  • Оценка тяжести нарушения по превышению порога скорости

02 · веб-приложение

Памятка для водителей самосвалов

Водителю на карьере некогда искать инструкцию. Приложение открывается на планшете и доводит до нужной памятки за два нажатия: ярлык, список проблем, решение.

  • Памятки с текстом, картинками и видео, проблемы сгруппированы по тегам
  • Адаптивная вёрстка для планшета, телефона и ПК
  • Админка на KeystoneJS: специалисты без опыта разработки сами добавляют, меняют и удаляют памятки
  • Фронтенд на React получает данные через GraphQL
  • Инструкция для пользователей админки
